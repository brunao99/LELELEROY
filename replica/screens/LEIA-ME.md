# Prints de referência

Prints do CapCut no celular, tirados usando o app normalmente. Servem só para
comparar o layout (`/replica-diff`) e **nunca** entram no nosso app.

Nomeie cada arquivo com o ID da tela (`S03.png`, `S07.png`...). Se uma tela tiver
mais de um estado, use um sufixo: `S01-vazio.png`, `S15-gerando.png`.

Use um projeto com pelo menos 3 clipes, 1 texto, 1 música e legendas, assim a
timeline aparece cheia.

- [ ] S01 Início: com projetos e, se der, vazio
- [ ] S02 Seletor de mídia com 3 itens selecionados
- [ ] S03 Editor sem nada selecionado (timeline com várias faixas)
- [ ] S04 Editor com um clipe selecionado (barra de ferramentas do clipe)
- [ ] S05 Velocidade (aba Normal)
- [ ] S06 Volume e Fade
- [ ] S07 Texto: teclado aberto, aba de estilo e aba de animação
- [ ] S08 Menu de Áudio
- [ ] S09 Editor com um áudio selecionado
- [ ] S10 Filtros
- [ ] S11 Ajustar
- [ ] S12 Transições (tocar no ícone entre dois clipes)
- [ ] S13 Formato
- [ ] S14 Fundo
- [ ] S15 Legendas automáticas: antes de gerar e durante
- [ ] S16 Edição em lote das legendas
- [ ] S17 Exportar: opções de resolução, progresso e concluído
- [ ] S18 Sobreposição selecionada
- [ ] S19 Editar (girar, espelhar, recortar)
- [ ] S20 Configurações

Não precisa: nada da pasta de instalação, arquivos internos ou gravações de rede.
