# LELELEROY

- [`bobina/`](bobina/): **Bobina**, editor de vídeo para Android e iOS (Expo /
  React Native) com timeline, cortes, velocidade, texto, áudio, filtros,
  transições, legendas automáticas no celular e exportação em MP4. Como rodar
  no celular: [`bobina/README.md`](bobina/README.md).
- [`replica/`](replica/): planejamento e verificação do Bobina: mapa de
  funcionalidades (`recon.md`, `features.csv`), arquitetura, design, plano de
  testes, bugs, marca e paridade (`parity.md`).
- [`.claude/skills/`](.claude/skills/): o pacote de skills Replica usado para
  planejar e construir o app.
